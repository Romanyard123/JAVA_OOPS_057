# Project Overview

This repository contains my solutions for **Lab 01 – Thinking in Objects**. The objective of this lab is to understand the fundamentals of Object-Oriented Programming (OOP) by designing classes, creating UML diagrams, and implementing the classes in Java.

The repository includes two independent demonstrations:

- **Calculator Demo**
- **Car Demo**

Each project contains its own Java source files, UML diagram, program output, and documentation.

# How to Run

### Clone the repository

```bash
git clone <repository-link>
```

### Navigate to the desired project

Example:

```bash
cd CalculatorDemo
```

Compile the program:

```bash
javac *.java
```

Run the program:

```bash
java Main
```

Repeat the same steps for the Car Demo.
