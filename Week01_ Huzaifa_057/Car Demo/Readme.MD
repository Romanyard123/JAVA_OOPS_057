# Project Description

This project demonstrates the implementation of a simple Car class using Object-Oriented Programming concepts in Java.

The Car object stores information about a vehicle such as speed, steering angle, fuel level, average fuel consumption, and engine status. Various methods simulate the behavior of a real car.

---

# Features

The Car class supports the following operations:

- Start Engine
- Stop Engine
- Change Speed
- Move Forward
- Turn Right
- Parking
- Move Fast
- Move Slow
- Turbo Mode
- Display Car Information

The program also checks whether the engine is started before allowing the car to accelerate.

