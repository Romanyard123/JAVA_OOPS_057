# Project Description

This project demonstrates the implementation of a simple **Calculator** class using the basic principles of Object-Oriented Programming in Java.

The project uses:
- Classes and Objects
- Constructor
- Encapsulation
- Getter and Setter Methods
- Member Functions (Methods)
- Conditional Statements
- Basic Arithmetic Operations

The calculator stores two integer values and performs various mathematical operations on them.

---

# Features

The Calculator class provides the following functionalities:

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Maximum Number Finder
- Display Current Values

The program also handles important edge cases such as division by zero and modulus by zero.

# How to Run

1. Compile the Java files:

```bash
javac Calculator.java Main.java
```

2. Run the program:

```bash
java Main
```
